# 모의개미 · 앱인토스(Apps in Toss) 미니앱 패키지

`/workspace/mock_stock_app.html` (원본 단일 HTML 앱)을 **앱인토스 WebView 미니앱**으로 올릴 수 있게 패키징한 프로젝트입니다.

- 앱 이름(국문): **모의개미**
- 영문명: **Moeigami**
- appName: **`moeigami`** (콘솔 등록값과 반드시 동일해야 함)
- 유형: **가상 주식 시뮬레이션 게임** — 실제 돈·실제 주식·실제 결제 없음

## 빠른 시작

```bash
# Node.js 24 LTS 권장 (@apps-in-toss/web-framework 3.10.0의 engines: node >= 24)
cd /workspace/moeigami-ait
npm install
npm run dev      # http://localhost:3000 로컬 미리보기
npm run build    # dist/ 빌드 + moeigami.ait 생성
```

빌드 결과물: **`/workspace/moeigami-ait/moeigami.ait`**

## 구조

```
moeigami-ait/
├─ apps-in-toss.config.ts    # SDK 3.x 설정 (appName, webView, navigationBar)
├─ vite.config.js            # base: './' (번들 내 상대 경로)
├─ scripts/prepare.mjs       # 원본 HTML → index.html 로 복사하며 브리지 스크립트 주입
├─ src/ait-bridge.js         # 토스 앱에서만 동작하는 backEvent → 네비게이션 브리지
├─ index.html                # (자동 생성) 원본 앱 사본
├─ dist/                     # 웹 번들 산출물 (index.html + assets)
├─ moeigami.ait              # 콘솔 업로드용 앱 번들
└─ store/                    # 로고·스크린샷·썸네일·콘솔 문구 초안
```

`npm run build` 순서: `prepare.mjs`(원본 복사+브리지 주입) → `vite build` → `ait build`(번들 패키징).
원본 `/workspace/mock_stock_app.html`은 건드리지 않고 그대로 두며, 번들용 사본만 만듭니다.

## 앱인토스 연동 내용

- **설정 파일**: SDK 3.x 규격 `apps-in-toss.config.ts` (`granite.config.ts`는 2.x 이름)
  - `webView`: 바운스/풀투리프레시/오버스크롤 끔, iOS 스와이프 뒤로가기 끔
  - `navigationBar`: 뒤로가기·홈·타이틀 노출, 라이트 테마
- **뒤로가기**: `graniteEvent.addEventListener('backEvent', …)`
  - 상세/거래내역/방문 화면에서는 앱 내부 이동, 탭 루트에서는 `Screen.close()`로 미니앱 종료
  - 토스 안에서는 앱이 자체적으로 그리던 뒤로가기 버튼(`.backbtn`)을 CSS로 숨겨 **중복 뒤로가기 버튼을 방지**
- **뷰포트**: `maximum-scale=1, user-scalable=no`로 핀치 줌 차단
- **외부 의존성 없음**: 외부 스크립트/iframe/fetch/eval 없이 단일 HTML로 동작 (출시 가이드 준수)

## 이번에 앱에 추가된 기능

1. **거래 수수료** — 매수 0.05%, 매도(청산 포함) 0.15%. 주문 카드의 `총 주문금액` 아래에 `수수료 (0.05%)`로 예상 수수료 표시, 체결 시 예수금에서 실제 차감, 거래내역·토스트에 기록. 지정가(예약) 주문과 레버리지 진입/청산에도 동일 적용.
2. **🔥 급등주 2종** — `하이퍼개미랩(HPRL)`, `초전도개미(SCDT)`. 일반 종목보다 훨씬 큰 변동성(2026-11-16 4차 업데이트에서 초고변동성으로 상향), 확률적으로 급등/급락 랠리, 목록·상세에 `🔥 급등주` 배지.
3. **🆕 무작위 신규 상장** — 창작 조합명(솜사탕·별무리·초코칩… × 로보틱스·바이오·랩스…), 가상 티커. 상장 직후 22초간 변동성 버프, 최대 4개 유지(5번째 상장 시 보유하지 않은 가장 오래된 종목 정리), localStorage에 저장. 상장 시 토스트 `🆕 [종목명] 신규 상장! 지금 거래 가능` + 뉴스 피드 동시 노출.
4. **긴급 속보 자동 만료** — 미선택 속보는 **15초** 뒤 자동으로 사라지며 카드에 남은 시간이 표시됨. 선택하면 만료되지 않음.
5. **뉴스/속보 발생 간격 완화** — 120~300초(2~5분)로 조정. 일반 뉴스는 토스트 없이 피드에만 쌓이고, 긴급 속보만 배너(토스트) 노출.
6. **상점 패시브 수익** — 먹거리를 제외한 모든 아이템이 **가격의 5%/분**. 단, **집(개미굴) 꾸미기 슬롯에 배치된 아이템만** 실제 수익 발생(실시간 틱 + 오프라인 복귀 정산, 포만감 0% 구간 제외). 상점 카드에 `배치 시 +N원/분 (5%)`, 내 집 화면에 `지금 배치 수익 +N원/분` 표시.
7. **먹거리 회복량 전부 다르게** — 가격 순위 14종이 `12% → 100%`로 모두 다른 고유값. 자산이 커지면 입맛 보정 배율이 적용되지만 순위별 차이는 유지(최소 5%부터).

## 2026-11-19 7차 업데이트 (⏱ 복귀 리포트 · 오늘 손익) — 후보 버전 20261119-13

다시 열었을 때 "내 계좌에 무슨 일이 있었는지"가 바로 보이게 했습니다.

1. **⏱ 복귀 리포트** — 10분 이상 앱을 비웠다 돌아오면, 아래에서 올라오는 카드 한 장으로 `비운 시간`·`총자산 변화(금액·%)`·`오늘 가장 오른 종목`·`연속 출석`·`오늘의 미션 진행`을 보여 줍니다. `시장 보기`를 누르면 홈으로 돌아가고, 복귀할 때마다 한 번만 뜹니다.
2. **오늘 손익 줄** — 홈 자산 카드의 총 수익률 아래에 `오늘 +1,234,567원 (+1.2%)`을 추가했습니다. 자산이 오르내릴 때마다 실시간으로 바뀌고, 날짜가 바뀌면 그 시점 자산을 새 기준으로 잡습니다(`state.dayOpen`, 저장 키 `moeigami_v2` 안에 함께 저장 — 기존 저장 데이터 유지).
3. **하루 첫 접속 오프라인 정산 복구** — 출석 보상 저장이 `lastTickAt`을 당겨서 **그날 첫 접속에는 부재중 진행이 통째로 건너뛰어지던 문제**를 고쳤습니다. 이제 출석 전에 잡아 둔 마지막 접속 시각으로 정산해 복귀 리포트와 패시브 수익이 함께 들어옵니다.

검증(헤드리스 Chromium 390×844, 빌드된 dist 기준, 콘솔 에러 0건): 어제 상태(예수금 500만원 + 1종목 보유, 2시간 전 접속)로 열었을 때 리포트 카드가 `2시간 만에 돌아왔어요 · +448,000원 · 총자산 +4.09%`로 뜨고 행(오늘 가장 오른 종목·연속 출석·미션)이 채워지는지, `시장 보기`로 시트가 닫히는지, 새로고침해도 오늘 손익 기준이 유지되는지(0으로 리셋되지 않음), 같은 날 재접속에는 리포트가 다시 뜨지 않는지, 매수·상세·거래내역·랭킹·상점·챌린지가 그대로 동작하는지 확인했습니다.

## 2026-11-16 6차 업데이트 (🏆 총자산 순위 랭킹) — 버전 20261116-11

랭킹 탭이 수익률만 보여 주던 것을, **지금 총자산이 가장 많은 개미부터 차례대로** 나오게 바꿨습니다.

1. **기본 정렬 = 💰 총자산 순** — 나와 라이벌 개미 10명을 `총자산 = 원금 × (1 + 수익률)`로 계산해 많은 순으로 줄을 세웁니다. 내 총자산은 틱마다 다시 계산해 실시간으로 반영되므로, 수익이 나면 순위가 바로 올라갑니다.
2. **`💰 총자산 순` | `📈 수익률 순` 토글 칩** — 랭킹 히어로 카드 아래에 두 칩을 두었고, 누른 정렬은 `localStorage`에 저장돼 앱을 다시 열어도 유지됩니다.
3. **각 줄에 총자산 + 수익률 함께** — 총자산은 `12억 4,500만원`처럼 크게, 수익률은 그 아래 `+1,145%`처럼 붉은색/파란색으로 함께 표시합니다. 1~3위는 🥇🥈🥉 메달, 내 줄은 초록 배경 + `MY` 배지.
4. **라이벌 10명을 실제 부자 순으로** — 라이벌마다 원금(레벨 자산표 Lv.3~Lv.66 기준)과 고유 수익률 성향(물타기대마왕 -14% … 슈팅스타 +28%)을 주고, 3.6초마다 성향 쪽으로 살짝 되돌아가며 흔들리게 해 총자산이 조금씩 움직입니다. 내 자산이 커지면 아래쪽 라이벌부터 하나씩 앞지르고, 최상위 존버장인(86조원)을 넘으면 1위입니다.
5. **라이벌 집 목록도 같은 값으로** — 상점 > 내 집 > 라이벌 집 목록이 Lv.2~Lv.66·실제 총자산·수익률로 표시되고, 방문 화면의 자산/집 단계도 랭킹과 같은 숫자를 씁니다.
6. **표기 정리** — 라이벌 총자산은 유효숫자 3자리(`1억 7,900만원`), 수익률은 1,000% 이상이면 소수점 없이(`+1,145%`), 1만% 이상은 `123만%`·`12억%`로 줄여 한 줄에 들어가게 했습니다.

검증(헤드리스 Chromium 390×844, 빌드된 dist 기준, 콘솔 에러 0건): 기본 진입이 총자산 내림차순(86조 1,000억 → … → 1,100만원, 11줄)인지, 내 자산 5조원일 때 2위 / 1,200만원일 때 11위 / 12억 4,500만원일 때 7위로 순위가 따라 움직이는지, `📈 수익률 순` 클릭 시 수익률 내림차순으로 바뀌고 새로고침 후에도 그 정렬이 유지되는지, 6초 사이 라이벌 수익률·총자산이 흔들리는지, 360px 폭·1경 자산·12자 닉네임에서도 줄이 넘치지 않는지 확인했습니다.

## 2026-11-16 5차 업데이트 (계좌 초기화 기준 1,000만원 미만) — 버전 20261116-2

- 계좌 초기화 가능 조건을 **총자산 100,000원 미만 → 10,000,000원(1,000만원) 미만**으로 올렸다(`RESET_BROKE_LIMIT`). 새 계좌의 시작 예수금이 정확히 1,000만원이라 시작 직후에는 초기화할 수 없고, 그 아래로 떨어져야 초기화된다.
